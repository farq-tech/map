# جدول «ميزة قديمة ← مكانها الجديد» — المجموعة B

لا ميزة محذوفة. كل التغييرات خلف `NewUI.enabled`، والواجهة القديمة هي الافتراضية.

| ميزة قديمة | مكانها في الواجهة الجديدة |
|---|---|
| ترويسة `SaryPage` (عنوان، سطر فرعي، رجوع، إغلاق، أزرار trailing) | `NewPageHeader`: العنوان يمين، ✕ دائري يسار، نفس المعرّفات `page-close` `page-back`، الأزرار trailing قبل ✕ |
| «خلاص» (إغلاق الطقس) في شريط التنقل | ✕ الترويسة `weather.close` |
| «حدّث» (أيقونة تحديث الطقس) | زر دائري `weather.refresh` في الترويسة (+ معرّف جديد) |
| كل أقسام الطقس (بطاقات، وصول، وجهة، أودية، NCM، إخلاء) | نفس المحتوى والترتيب داخل `newBody` |
| صفوف الإعدادات 43 / صفوف التنقل 48 | ارتفاع موحد 56 |
| القبلة: دوّامة/«اسمح للموقع»/«إعدادات الموقع»/«حاول مرة ثانية» | نفس الحالات والمعرّفات؛ الأزرار صارت رئيسية 58 |
| «اتجه» في كل بطاقة كشتة | البطاقة 1 رئيسي، الباقي ثانوي (نفس المعرّف `camp.go.N`) |
| دروب البر | بلا تغيير وظيفي (الترويسة فقط) |
| ملفي: صورة/اسم/جوال/حفظ/رمز الاسترجاع/الإعدادات/خروج | نفسها (الترويسة والصفوف فقط) |
