# أداة وسم دروب الصحراء — سَرى البارق

أداة تفاعلية يستعملها المالك بنفسه ليعلّم نموذج **SAM-Road** اكتشاف دروب البر من صور الأقمار الصناعية. تعمل محليًا: واجهة متصفح (Leaflet) + خادم FastAPI صغير + مكتبات جيومكانية حقيقية (rasterio / pyproj / shapely).

> بحث/تجهيز بيانات فقط. لا تغيير في التطبيق، ولا **أي تدريب** هنا. لا يبدأ تدريب قبل أن يقول تقرير الجودة «جاهز للتدريب: نعم».

## التشغيل بثلاثة أوامر

```bash
cd tools/track-annotator
make setup                                              # بيئة Python 3.12 + المتطلبات
echo 'MAPBOX_ACCESS_TOKEN=pk.xxxxx' > .env.local       # مفتاح Mapbox العام فقط (أو ضعه في .env.local بجذر المستودع)
make run                                                # ثم افتح http://127.0.0.1:8791
```

اختبارات: `make test`. المفتاح يُقرأ داخل البرنامج فقط ولا يُطبع ولا يُكتب في أي ملف ناتج.

## الصور (حقيقية فقط)

- المصدر: بلاطات Mapbox Satellite **z17 @2x ≈ 0.54 م/بكسل** (عند خط عرض 25.5°) تمر عبر الخادم، تُخزَّن على القرص، وتحكمها **ميزانية طلبات يومية** (افتراضيًا 600 بلاطة جديدة؛ `MAPBOX_DAILY_BUDGET`). لا تنزيل جماعي: فقط النافذة التي تختارها (3×3 بلاطات ≈ 830 م ≈ 9 طلبات كحد أقصى).
- **z18 وما فوق مجرد تكبير** لـ z17 بلا تفاصيل جديدة؛ الواجهة تعرض تحذيرًا عند تجاوز الدقة الحقيقية والخادم يرفض إنشاء عينة بغير z17.
- تُدمج البلاطات في **GeoTIFF بنظام EPSG:3857 وبمحول دقيق بلا إعادة أخذ عينات**. تاريخ الالتقاط مجهول (`imagery_date: unknown`). الترخيص مسجَّل في كل عينة: `owner-declared`.
- **استيراد GeoTIFF**: اسحب الملف فوق الخريطة أو زر «Choose File» أو `python -m annotator import ملف.tif [--crop lon0,lat0,lon1,lat1]`. يُحفظ الأصل بقيمه وCRS ومحوّله كما هو (يُرفض الملف بلا CRS)؛ 16-بت أو أكثر من 3 نطاقات يُعرض بتمطيط 2–98% للعرض والتصدير فقط.

## الرسم والتعديل

| الأداة | الاختصار | الوصف |
|---|---|---|
| تحديد/تعديل | V | انقر مسارًا؛ اسحب النقاط؛ نقر مزدوج على الخط يضيف نقطة؛ نقر يمين على نقطة يحذفها |
| خط الوسط | C | انقر لإضافة نقاط، نقر مزدوج أو Enter للإنهاء، Backspace آخر نقطة، Esc إلغاء |
| حافة | E | حافة اختيارية مرتبطة بالمسار المحدد (تُوسَم left/right تلقائيًا) |
| حذف / تراجع / حفظ | Delete / Ctrl+Z / Ctrl+S | حذف مسار يحذف حوافه |

عدة مسارات في الصورة الواحدة. كل مسار: **النوع** (رملي sandy، ترابي dirt، صخري rocky، مختلط mixed، متعرج winding، أثر مركبات خافت faint) و**الوضوح** (1 واضح … 4 شبه خفي). وللعينة: **التضاريس** (سهل رملي، كثبان، حصوي، صخري، وادٍ، سبخة، مختلط) ووضوح عام وملاحظات. الرسم يُخزَّن بإحداثيات WGS84 كما نقرتها (لا تقريب لبكسلات).

## ما يُحفظ لكل صورة موسومة

`data/samples/<sample_id>/` — المعرّف `s<12 hex>` **حتمي** (من بصمة النافذة/الملف) فلا تتكرر العينة ولا يُطلب جلبها مرتين.

| الملف | المحتوى |
|---|---|
| `image.tif` | الصورة الأصلية GeoTIFF بـ CRS والمحول الأصليين |
| `tracks.geojson` | المسارات (WGS84، RFC 7946): `centerline` + `edge`، مع النوع والوضوح |
| `mask.png` / `mask.tif` | قناع ثنائي على **شبكة بكسلات الصورة نفسها** (الـ tif يحمل الجيورفرنس) |
| `mask_types.png`, `mask_edges.png` | قناع فئات (1..6 = النوع) وقناع الحواف |
| `overlay.png` | القناع + المتجهات فوق الصورة (دليل المحاذاة) |
| `metadata.json` | المعرّف، CRS والمحول والحدود، الدقة الأرضية، التضاريس، الوضوح، المصدر، الترخيص، إحصاءات الطول، بصمات |

عرض القناع **فيزيائي** (3 م افتراضيًا): تُوسَّع الخطوط في UTM محلي ثم تُنقل إلى CRS الصورة وتُرسَّم بمحوّلها، فهو صحيح للصورة بأي CRS.

## الجمع الذكي (دفعة واحدة)

تبويب «طلب الدفعة» أو `python -m annotator batch`:

1. يحلل كل ما وسمته (عينات المالك فقط؛ عينات `fixture` البرمجية لا تُحتسب) ويقارنه بأهداف `config/targets.json` (مسارات / كم / مناطق مكانية لكل نوع).
2. يجمع كل النواقص في **طلب واحد** يسمي الأنواع الناقصة ويقترح نوافذ z17 حقيقية (`config/candidates.json`: 231 نافذة في 157 خلية 10 كم، من خطوط OSM المرسومة لدينا ومناطق الدراسة السابقة؛ تُولَّد بـ `scripts/build_candidates.py` ولا تُعتبر حقيقة أرضية، والحكم بصريًا لك).
3. **لا يعيد طلب** نافذة زوّدتنا بها (تتداخل ≥30% مع صورة وسمتها)، ولا نافذة تخطيتها، ولا نوافذ دفعة سابقة؛ استدعاء ثانٍ يعيد الدفعة المفتوحة نفسها. دفعة جديدة لا تُنشأ إلا بعد إتمام الحالية.
4. أمثلة مولَّدة: [docs/first-batch-request.md](docs/first-batch-request.md).

تلميحات الأنواع من OSM ضعيفة: `track_grade4/5`→رملي، `track`/`grade2-3`→ترابي، `grade1-2`→صخري (ثقة منخفضة جدًا)، `grade3`→مختلط، التعرج = sinuosity ≥1.25، `path`/`grade5`→أثر خافت.

## التصدير لـ SAM-Road

```bash
python -m annotator export [--gsd 1.0] [--tile 400] [--block-km 5] [--buffer-m 500] [--seed 0]
```

**الهدف**: `htcr/sam_road` (CVPRW 2024) commit `04b67c503f120ecff2b2dc5a2041ea6d300e306a`، فرع `spacenet` في `dataset.py`؛ وSAM-Road++ (`earth-insights/samroadplus`) يذكر في README أن تجهيز البيانات «refer to the sam_road repo» (الصيغة نفسها؛ لم نشغّله). الأدلة: `README.md` (Data Preparation)، `dataset.py` (`SatMapDataset`, `coord_transform = (r,c)→(x, 400−r)`)، `spacenet/generate_labels.py` (`IMAGE_SIZE=400, KEYPOINT_RADIUS=3, ROAD_WIDTH=3`)، `config/toponet_vitb_256_spacenet.yaml`. الاختبار `test_graph_masks_equal_vendored_generate_labels` يشغّل سكربت SAM-Road نفسه على رسمنا ويطابق الأقنعة بكسلًا ببكسل.

```
exports/<إصدار>/
  spacenet/RGB_1.0_meter/{id}__rgb.png        بلاطة 400×400 RGB
  spacenet/RGB_1.0_meter/{id}__gt_graph.p     pickle {(r,c):[(r,c)…]}  (r = 400 − y, c = x)
  spacenet/processed/road_mask_{id}.png, keypoint_mask_{id}.png
  spacenet/data_split.json                    {"train":[…],"validation":[…],"test":[…]}
  extras/{id}__geo.json | __tracks.geojson | __type_mask.png   الجيورفرنس (UTM) والمتجهات المقصوصة وفئات الأنواع
  manifest.json  quality_report.json/.md  README_EXPORT.md
```
انسخ `spacenet/` إلى جذر مستودع sam_road. كل البلاطات تُعاد إسقاطها إلى **UTM محلي** بدقة أرضية `--gsd` (1.0 م = توزيع SAM-Road) فيكون البكسل متريًا. اسم الإصدار `v<تاريخ>-<بصمة المدخلات>`؛ يحتفظ `manifest.json` بالمعاملات وبصمات الصور والوسوم والترخيص (`owner-declared`).

### التقسيم المكاني بلا تسرب
البلاطات تُنسب إلى **كتل مربعة 5 كم** (EPSG:6933)؛ الكتلة كلها إلى قسم واحد (تدريب 70 / تحقق 15 / اختبار 15، خوارزمية حتمية بـ `--seed`)، ثم تُحذف بلاطات قسم أدنى تقل مسافتها عن **حاجز 500 م** من قسم آخر. `leakage_check` يعيد القياس من الملفات: أدنى مسافة بين الأقسام وأي تداخل. لا تقسيم عشوائي للبلاطات أبدًا (اختبار يثبت أنه يسرّب).

### تقرير الجودة (`quality_report.md`)
تغطية القناع، الأقنعة الفارغة، عرض الخط (distance transform)، انحراف القناع عن الخط جغرافيًا (بكسلات القناع → lon/lat → المسافة للخط، ونسبة وقوع الخط على القناع)، ذهاب/عودة بكسل↔جغرافيا، تناظر الرسم وحدوده، تجانس الصورة، توازن الأنواع لكل قسم. حكمان منفصلان: **السلامة** و**الكفاية** (حد أدنى للبلاطات والأنواع والكتل في `config/targets.json`). ملاحظة: `cv2.line(...,3)` في سكربت SAM-Road نفسه يرسم ≈5 بكسل عرضًا، فنطابقه ولا «نصلحه».

## الاختبارات

`make test` — 38 اختبارًا: ذهاب/عودة بكسل↔جغرافيا (Mercator وUTM)، محاذاة GeoJSON→قناع (3 أنظمة CRS)، تخزين/استيراد/تحقق، تقسيم بلا تسرب ومكشف التسرب، صيغة التصدير ومطابقة سكربت SAM-Road، التحليل والدفعة (عدم إعادة الطلب)، الـ API، ذاكرة البلاطات والميزانية وعدم تسرب المفتاح. الاختبارات لا تستعمل الشبكة؛ الصور الاصطناعية فيها لاختبار الهندسة فقط ولا تدخل البيانات.

## حدود معروفة

- مرشحات النوافذ من OSM: قد تقع قرب مزارع/مدن (مثال النافذة الأولى قرب مزرعة محوري)؛ تلميحات «صخري» و«خافت» ضعيفة جدًا.
- صورة واحدة بلا تاريخ التقاط؛ أثر الرمل يتغير.
- بلاطة z17@2x ضبابية: الدروب الخافتة قد لا تُرى بصريًا حتى للإنسان.
- النوافذ المقترحة تُجلب بنقرة؛ لا جلب تلقائي جماعي (بالتصميم).
- تعديل الرسم في الواجهة بلا تعدد مستخدمين ولا قفل ملفات (أداة المالك الفردية).
- البيانات في `data/` و`exports/` خارج git؛ الصور مرخَّصة بإعلان المالك فقط.
