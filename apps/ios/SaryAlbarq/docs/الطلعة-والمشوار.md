# الطلعة والمشوار — نموذج واضح للرحلة

> ملاحظة المالك (رحلة حقيقية): «عند الدخول إلى طلعة لا أعرف هل أنا بديت الرحلة ولا لا». والمفهوم كان مخلوط: الرحلة A→B تنتهي، والطلعة/الكشتة ما تنتهي إلا لين يرجع الكل.

## النموذج

| المفهوم | المعنى | يبدأ |
|---|---|---|---|
| **الطلعة** (outing) | الحاوية: المجموعة، المشاركة المباشرة، الدردشة، القناة، SOS | أمير الرحلة يضغط «ابدأ الطلعة» |
| **المشوار** (leg) | من A إلى B، بتوجيه | «ابدأ المشوار» بعد «وين رايحين؟» |

- مثال: البيت ← محطة الوقود ← المخيم ← (ثاني يوم) المخيم ← الروضة ← البيت. هذي **طلعة وحدة فيها ٥ مشاوير**.
- **مشوار المجموعة**: يبدأه الأمير ويوجّه الكل («وجّه الكل»/«لي فقط»). يظهر لكل الأعضاء. وصول الأمير ينهيه للكل.
- **مشواري**: أي عضو يقدر يبدأ مشوار لنفسه (مثلًا للبنزينة). يشوفه هو بس.
- يصلح في المدينة مثل البر: «وين رايحين؟» فيها البحث عن أي مكان (بحث PR #111: الأماكن وشوارع فرق)، وأماكن سابقة، وأماكني، ونقطة البداية. واقتراحات الكشتة (PR #110) تدخل هنا لاحقًا كقسم إضافي.

## الحالات والانتقالات

```
            (الأمير)                     وين رايحين؟                 ابدأ المشوار
ما بدأت ──ابدأ الطلعة──▶ شغّالة (بلا مشوار) ───────────▶ مختارين وجهة ───────────▶ في الطريق إلى X
                              ▲    ▲                         │  غيّر                     │
                              │    └─────────────────────────┘                          │ وصلنا / وصول تلقائي
                              │                                                          ▼
                              └──────────── وين رايحين؟ ◀──────────────────── واقفين عند X  («وصلنا X 🎉» لحظة ٩٠ ث)
                                                                                         │
   انتهت الطلعة ◀──────────────── أنهِ الطلعة (تأكيد) ◀──────── (شغّالة / واقفين / اقتراح الإنهاء)
        │
        └─▶ ملخص الطلعة (فيه كل المشاوير)
```

متوقفة مؤقتًا: حالة جانبية من «شغّالة»، وما فيها زر رئيسي.

## النص لكل حالة (نجدي)

| الحالة | السطر الثاني في الترويسة | الزر الرئيسي الوحيد |
|---|---|---|
| ما بدأت، الأمير | «ما بدأت الطلعة» | **ابدأ الطلعة** |
| ما بدأت، عضو | «بانتظار أمير الرحلة يبدأ» | «بانتظار أمير الرحلة يبدأ» (غير قابل للضغط، مع مؤشر) |
| شغّالة بلا مشوار | «الطلعة شغّالة · ٤ مباشر» | **وين رايحين؟** |
| مختارين وجهة | «الوجهة مخيم النفود · جاهزين؟» | **ابدأ المشوار** |
| في الطريق | «في الطريق إلى مخيم النفود · ١٢ كم · ١٨ د» | **وصلنا** |
| وصلنا | «واقفين عند مخيم النفود» (ولحظة الوصول toast واحد ٤ ثواني، أو بطاقة «وصلتوا» للتوجيه ٤ ثواني) | **وين رايحين؟** |
| اقتراح الإنهاء | «واقفين عند …» / «الطلعة شغّالة …» | **أنهِ الطلعة** |
| تأكيد الإنهاء | «أنهِ الطلعة للكل؟» — «تتوقف المشاركة عند الكل ويطلع ملخص الطلعة بكل مشاويرها.» | «أنهِ الطلعة» (أحمر) |
| انتهت | «انتهت الطلعة» | **ملخص الطلعة** |
| متوقفة | «الطلعة متوقفة مؤقتًا» | — |

رسائل قصيرة: «بدأت الطلعة · وين رايحين؟» · «يلا! في الطريق إلى X» · «وصلت X 🎉» · «وصل فلان X».

## قواعد الزحمة (مراجعة المالك: «زحمة»)

1. **الوصول يُقال مرة وحدة.** الترويسة: «واقفين عند X». واللحظة: toast واحد لمدة ٤ ثواني (أو بطاقة «وصلتوا» حق التوجيه، وتختفي بعد ٤ ثواني). وأرقام المشوار داخل ورقة «الرحلة» بس، والورقة ما تنفتح لحالها.
2. **زر رئيسي واحد بكل حالة.** «أنهِ الطلعة» و«غادر الطلعة» داخل ورقة «الرحلة» تحت، بأسلوب ثانوي. «غيّر الوجهة» رابط هادئ في «سجل الطلعة».
3. **SOS في مكانه الثابت يسار، وما يتداخل معه شي.** ما فيه زر بيت على الخريطة، و«نقطة البداية» داخل «وين رايحين؟».
4. **زر كبير واحد تحت.** وقت الوقوف: الزر الرئيسي كبير، و«اضغط وتكلم» دائري جنبه. وقت القيادة العكس: اللاسلكي كبير، و«وصلنا» مضغوط.
5. **عنقود الخريطة زرّين بالكثير** (موقعي + أدوات). «طريق الرجعة» داخل «أدوات» و«وين رايحين؟».
6. **الورقة:**
   - المشاركة شريط رفيع: «موقعك مُشارَك مع الطلعة · غادر الطلعة».
   - تنبيه «دائمًا» شريط صغير يطلع مرة وحدة وتقدر تقفله.
   - بعدها بطاقة الرحلة وحدها.
7. **الأرقام من مصدر واحد:**
   - «قطعنا» و«المدة» تبدأ من بداية المشوار نفسه، مو بداية الطلعة.
   - صفر أو أقل من دقيقة ما ينعرض.
8. **التغطية:** الخريطة مغطاة أقل من ٤٠٪ وقت الوقوف، وأقل من ٢٥٪ وقت القيادة. والعناصر الثابتة ٧–٨ بالكثير:
   - الترويسة؛
   - SOS؛
   - زرّين؛
   - الزر الرئيسي؛
   - اللاسلكي؛
   - مقبض الورقة.

## الإطارات (wireframes)

ثابت في كل الحالات: الترويسة فوق (اسم الطلعة + سطر الحالة + الطقس + السجل + الإعدادات)، و**SOS دايم ظاهر** يسار صف التنبيه، و«اضغط وتكلم» تحت.

**١. ما بدأت — الأمير**
```
┌──────────────────────────────────────────┐
│ ‹ ● كشتة النفود الكبير          ☀ 24°  ⟲ ⚙ │
│     ما بدأت الطلعة                          │
└──────────────────────────────────────────┘
 (SOS)
              [ خريطة ]
┌──────────────────────────────────────────┐
│          ▶  ابدأ الطلعة                    │  ← زر رئيسي كبير
└──────────────────────────────────────────┘
                              [🎙 اضغط وتكلم]
════ ورقة: «الطلعة ما بدأت. ابدأها ويشارك الكل مواقعهم.» ════
```
**١ب. ما بدأت — عضو**
```
│ ‹ ● كشتة النفود الكبير                       │
│     بانتظار أمير الرحلة يبدأ                 │
┌──────────────────────────────────────────┐
│   ◌  بانتظار أمير الرحلة يبدأ              │  ← زجاجي، غير قابل للضغط
└──────────────────────────────────────────┘
```
**٢. شغّالة بلا مشوار**
```
│ ‹ ● كشتة النفود الكبير                       │
│     الطلعة شغّالة · ٤ مباشر                   │
┌──────────────────────────────┐  (🎙)
│   🔍  وين رايحين؟              │   ← اللاسلكي دائري جنبه
└──────────────────────────────┘
ورقة «وين رايحين؟»:  [🔍 ابحث عن مكان]
                     أماكن سابقة: محطة الوقود · مخيم النفود
                     أماكني: …     الرجعة: 🏠 نقطة البداية
```
**٣. في المشوار (سواقة)**
```
│ ‹ ● كشتة النفود الكبير                       │
│     في الطريق إلى مخيم النفود · ١٢ كم · ١٨ د  │
           [ خريطة + خط التوجيه ]
[السرعة 87] [🎙 اضغط وتكلم — كبير]   (🏁 وصلنا)  ← مضغوط
```
**٤. وصلنا**
```
│     واقفين عند مخيم النفود                   │
     [toast: وصلنا مخيم النفود 🎉]   ← ٤ ثواني ويختفي
┌──────────────────────────────┐  (🎙)
│   🔍  وين رايحين؟              │
└──────────────────────────────┘
```
**٥. الإنهاء** (من ورقة «الرحلة» ← «أنهِ الطلعة»، أو الزر الرئيسي إذا اقترحنا الإنهاء)
```
        ┌────────────────────────────┐
        │     أنهِ الطلعة للكل؟        │
        │ تتوقف المشاركة عند الكل      │
        │ ويطلع ملخص الطلعة بكل مشاويرها│
        │   [ أنهِ الطلعة ] (أحمر)     │
        │   [ لا، نكمل ]               │
        └────────────────────────────┘
```
**٦. الملخص**
```
ملخص الطلعة
[مدة الطلعة] [المشاركون] [مسافتي] [وقت الحركة]
المشاوير (٢)
 ● وصلنا محطة الوقود     ٤:١٠ ← ٤:٢٥ · ٨٫٢ كم · ١٥ د
 │
 ● وصلنا مخيم النفود      ٤:٤٠ ← ٥:٣٠ · ٣٤ كم · ٥٠ د
…
```
و«سجل الطلعة» نفس الخط الزمني داخل تبويب «الرحلة» أثناء الطلعة.

## البيانات والتوافق

- جدول جديد `sary.outing_legs` (ترحيل 016، إضافي فقط): `scope` group/personal، الوجهة (اسم ≤٤٠، إحداثيات)، `state` active/arrived/cancelled/ended، الأوقات، مجاميع المسافة والمدة من جوال صاحبها (بدون مسارات).
- مشوار نشط واحد للمجموعة، وواحد لكل شخص. بدء مشوار جديد يلغي النشط من نفس النوع (تغيير رأي ≠ مشوار، وما يظهر في السجل).
- API: `GET/POST /api/outings/:id/legs`, `POST …/legs/:legId/arrive`, `POST …/legs/:legId/cancel`. حدث `leg_updated` للمجموعة.
- **التوافق مع النسخ 20–22:** بدء مشوار المجموعة يكتب وجهته في `plan_destination` ويرسل `plan_updated`، فالنسخ القديمة تشوف المشوار الحالي كأنه «الوجهة». الأحداث الجديدة تتجاهلها القديمة.
- إذا الخادم ما عنده `/legs` (404): المشاوير تشتغل محليًا على الجوال بنفس القواعد.
- الخصوصية: مشواري ما يرجع إلا لصاحبه؛ بيت أي أحد ما يُعرف ولا يُحفظ (اقتراح الإنهاء يعتمد على نقطة بداية المجموعة فقط).
