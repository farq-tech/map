# تبسيط الواجهة: جرد الشاشات والقرارات

الفرع: `feat/ux-simplify-home`. المرجع: طلب المالك لتبسيط سَرى البارق، مع أخذ **تسلسل** تطبيق هدهد لا شكله. البر هو ما يميّزنا.

## المبدأ

- الخريطة أولًا. تفتح الخريطة وتحتها ورقة سفلية فيها بحث «وين رايحين؟»، ثم اختصارات ثم تصنيفات.
- الرحلة ثلاث خطوات: (أ) تختار الوجهة، (ب) «ابدأ» ثم «مين معك؟» (اختياري، بدعوة واتساب كما هي اليوم)، (ج) تبدأ الرحلة.
- أثناء الطلعة **ورقة واحدة صغيرة** فيها:
  - العنوان: الوجهة والوقت المتوقع، وعدد المباشرين.
  - إجراء رئيسي واحد: «ملاحة» أو «وجّه الكل».
  - صف من خمسة أزرار.
  - SOS يبقى كما هو.
  - كل ما يقل استخدامه ينتقل إلى «المزيد» أو «الإعدادات».
- لا يُحذف أي منطق خلفي. نحذف أو ننقل **مداخل الواجهة** فقط، ويبقى كل شيء ما لم يكن تكرارًا صريحًا.

## ١. الشاشة الرئيسية (كانت «طلعاتي»)

| العنصر | القرار |
|---|---|
| قائمة «طلعاتي» الكاملة كصفحة أولى | **دمج**: الصفحة الأولى صارت الخريطة. الطلعة الجارية بطاقة في أعلى الورقة («افتح الخريطة»)، وبقية الطلعات تحت «طلعاتي» في الورقة المسحوبة للأعلى |
| زر «طلعة جديدة» | **يبقى** داخل قسم «طلعاتي» في الورقة المسحوبة. الطريق الرئيسي صار: ابحث ← اختر ← «ابدأ» |
| «عندك رابط دعوة؟ انضم» | **يبقى** تحت «طلعة جديدة» |
| ترس الإعدادات + صورة الملف في رأس الصفحة | **دمج** في زر الملف داخل شريط البحث، ويفتح ورقة الملف |
| بحث الوجهة (كان في الخطوة ١ من المعالج فقط) | **نقل** إلى شريط البحث في الورقة: «وين رايحين؟ ابحث هنا»، مع زر مايك وزر الملف |
| — (جديد) | اختصارات: البيت، الشغل، المفضلة |
| — (جديد) | تصنيفات فوق الخريطة: مطاعم، مقاهي، مساجد، محطات وقود، نفود، روضة، فيضة، مخيمات، أمطار وربيع |
| — (جديد) | سحب الورقة للأعلى يعرض كل التصنيفات، و«أماكن سابقة»، و«طلعاتي» |

## ٢. تسلسل الرحلة

| الخطوة | القرار |
|---|---|
| معالج «طلعة جديدة» (١ الوجهة ← ٢ الجو ← ٣ الدعوة) | **يبقى** للطلعة المخططة («طلعة جديدة») |
| (أ) اختيار الوجهة | من البحث أو التصنيف أو الخريطة أو المفضلة. تظهر بطاقة المكان: الاسم، المسافة، «ابدأ»، «احفظ» |
| (ب) «ابدأ» ← «مين معك؟» | ورقة جديدة تنشئ الطلعة بالوجهة ووقت الآن. فيها دعوة واتساب أو دعوات شخصية (نفس آلية الدعوة الحالية)، و«مشاركة» و«انسخ». **اختيارية**: زر «ابدأ لحالي» |
| (ج) بداية الرحلة | الزر يفتح الخريطة ويبدأ الطلعة (نفس `pendingStart`) |

## ٣. ورقة الملف (زر الملف)

| البند | الوجهة |
|---|---|
| ملفي (الاسم، الصورة، الجوال) | رأس الورقة ← صفحة «ملفي» |
| مفضلتك | «أماكني المحفوظة»، والبيت والشغل |
| نشاطك | الطلعات السابقة |
| الإعدادات | صفحة الإعدادات العامة |
| المساعدة | صفحة «عن التطبيق» والدعم |
| الشروط | رابط شروط الاستخدام وسياسة الخصوصية |
| تسجيل الخروج | يبقى في «ملفي» |

## ٤. ورقة الطلعة (كانت ٣ تبويبات: الخريطة، العيال، الرحلة)

| العنصر | القرار |
|---|---|
| التبويبات الثلاثة | **حذف الشريط**: ورقة واحدة. صف الإجراءات ظاهر حتى والورقة مصغّرة، والسحب للأعلى يعرض العيال |
| ترس «الإعدادات» داخل الورقة | **حذف** (تكرار صريح): ترس رأس الخريطة يبقى |
| زر «+ أدوات» على الخريطة | **دمج** في زر «المزيد» آخر صف الورقة، بنفس المعرّف `outing-actions` |
| شريط «أخفِ موقعي · غادر الطلعة» | «أخفِ موقعي» **ينتقل** إلى صف الإجراءات. «غادر الطلعة» **ينتقل** إلى «المزيد ← الطلعة» |
| «غادر الطلعة» و«أنهِ الطلعة» في قائمة سفلية (ومكررة مرتين) | **مرة واحدة** في «المزيد ← الطلعة» مع «أوقف مؤقتًا» |
| «ابحث أو إحداثية» في الخطة وفي الأدوات | **تبقى مرة واحدة** في «المزيد» |
| «طريق الرجعة» (زر كبير) | **ينتقل** إلى صف الإجراءات |
| مفتاح «أظهر مسارات العيال» | **ينتقل** إلى الإعدادات ← مساري (موجود هناك أصلًا، والنسخة الثانية حُذفت) |
| نص الدقة («±٣م · ٦٠ نقطة/دقيقة») وتحذيرات GPS | **ينتقل** إلى الإعدادات ← مساري |
| تلميح «دائمًا» أو توفير الطاقة (مكرر) | **مرة واحدة**: يظهر فقط إن احتاج إجراء (إذن الموقع) |
| نموذج رقم الجوال في تبويب الرحلة | **حذف من الطلعة**: الرقم في «ملفي». الإعدادات فيها «رقم جوالي» ويفتح نفس الحقل |
| «سجل الطلعة» (المراحل) | **ينتقل** إلى «المزيد ← الوجهة والخطة» |
| «الوجهة والخطة» و«اتبع الخطة» | **ينتقل** إلى «المزيد ← الوجهة والخطة» |
| «وجّه الكل» | **إجراء رئيسي**: أول زر في الصف للقائد. لغيره «ملاحة» |
| بطاقة الطقس | **حذف من الورقة**: شارة الطقس في الرأس تبقى، و«المزيد ← طقس» |
| قسم السلامة (مؤقت الرجوع، غرّزت) | **ينتقل** إلى «المزيد ← السلامة» (لوحة)، وبلاطة «غرّزت» تبقى |
| بطاقة الرحلة (النسبة، حدّد الوجهة، أنهِ للجميع) | **ينتقل** إلى لوحة «الوجهة والخطة» |
| «المحادثات» (سطر في العيال + بلاطة) | **ينتقل** إلى صف الإجراءات (مع عدد غير المقروء) |
| قائمة العيال | **تبقى** في الورقة المسحوبة |
| القافلة، النقاط المشتركة | **تبقى** تحت العيال، وتظهر فقط حين يكون فيها شيء أو أنت القائد |
| بطاقة نقطة التجمع | **ينتقل** إلى صف الإجراءات ← لوحة نقطة التجمع |
| «ادعُ ربعك» (QR والرابط) | **ينتقل** إلى سطر «ادعُ ربعك» تحت العيال ← لوحة |
| تبويب الخريطة (الطبقة، الوضع الواقعي، بلا إنترنت، المؤثرات) | **دمج** في «المزيد ← الخريطة» و«الإعدادات» |

## ٥. «أدوات الطلعة» ← «المزيد» (كانت ~٢٢ بلاطة في ٦ أقسام)

| البلاطة | القرار |
|---|---|
| ملاحة | **ينتقل** إلى الإجراء الرئيسي في صف الورقة |
| ابحث أو إحداثية | **يبقى** |
| طريق الرجعة | **حذف من المزيد** (موجود في الصف) |
| اسلك هذا المسار / اتبع الخطة | **ينتقل** إلى لوحة «الوجهة والخطة» |
| المحادثات | **حذف من المزيد** (موجود في الصف) |
| الترددات | **يبقى** (إذا كان الخادم يدعمه) |
| وجّه العيال لنقطة | **حذف من المزيد** (هو الإجراء الرئيسي) |
| نقطة التجمع | **حذف من المزيد** (موجود في الصف) |
| القافلة، رسالة فوق سيارتي | **يبقى** |
| غرّزت، اتصل بإنجاد، مؤقت الرجوع | **يبقى** (مؤقت الرجوع يفتح لوحة السلامة) |
| بريف المكان، احفظ مكان، أضف نقطة | **يبقى** تحت بلاطة «مكاني» القابلة للتوسيع؛ تختصر ٣ إجراءات GPS مترابطة في مدخل واحد وتحافظ عليها كلها |
| الطقس والقبلة | **يبقيان** تحت «طقس واتجاه» القابلة للتوسيع، مع دخول مباشر بخطوة واحدة من «المزيد» |
| اقتراح الكشتة ودروب البر | **ينتقلان** إلى ورقة «الطبقات» قرب طبقات الخريطة؛ مدخل واحد لكل إجراء، ويُحذف تكرارهما من «المزيد» |
| أقرب محطة | **يبقى** مدخلًا مباشرًا لأن العثور عليها أثناء الطلعة إجراء سريع |
| إذاعة الطلعة، يوتيوب (قسم «الترفيه») | **ينتقل** إلى الإعدادات ← الإذاعة ويوتيوب (موجودة هناك أصلًا). القسم حُذف |
| الطبقات | **يبقى** |
| صور عالية الوضوح | **حذف** (تكرار: موجودة داخل «الطبقات») |
| المؤثرات | **حذف** (تكرار: كانت تفتح الإعدادات فقط) |
| الوضع الواقعي | **حذف** (تكرار: موجود داخل «الطبقات») |
| شوف الكل | **يبقى** |
| — (جديد) الوجهة والخطة، ادعُ ربعك | بلاطتان تفتحان لوحتيهما |
| — (جديد) قسم «الطلعة» | قائمة: الإعدادات، أوقف مؤقتًا أو استأنف، أنهِ الطلعة (للقائد)، غادر الطلعة |

تظهر ١٥ بلاطة عليا كحد أقصى عند تفعيل الترددات ووجود إجراء ملاحة للقائد. تُوسّع مجموعتا «مكاني» و«طقس واتجاه» داخل القسم نفسه؛ وتوجد اقتراحات البر داخل «الطبقات». تبقى جميع الإجراءات متاحة من مدخل واحد لكل منها.

## ٦. إعدادات الطلعة (الطلعة، الخريطة، الصوت واللاسلكي، الخصوصية، متقدم)

| البند | القرار |
|---|---|
| «نوع الطلعة» (صفحة «قريبًا») | **حذف** |
| «مشاركة موقعي» و«من يشوف موقعي» | **دمج** في صفحة واحدة: «موقعي ومن يشوفه» (الحالة، البطارية، الإشعارات) |
| — (جديد) «رقم جوالي» | يُنقل من تبويب الرحلة |
| «الوضع بدون إنترنت» | **يبقى** في «متقدم». التكرار في تبويب الخريطة حُذف |
| البقية | **تبقى** كما هي |
